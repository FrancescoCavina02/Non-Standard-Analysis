Partially ordered sets / Definition

Partially ordered set

Source indexedLarge Sets.tex:1424

Formal statement

A partially ordered set , or poset , is a pair
(P,≤), (P,\leq), (P,≤),
where PPP is a set and ≤\leq≤ is a relation on PPP satisfying:

• p≤pp\leq pp≤p for every p∈Pp\in Pp∈P;
• if p≤qp\leq qp≤q and q≤pq\leq pq≤p, then p=qp=qp=q;
• if p≤qp\leq qp≤q and q≤rq\leq rq≤r, then p≤rp\leq rp≤r.

The elements of a partially ordered set need not all be comparable. It may
happen that neither p≤qp\leq qp≤q nor q≤pq\leq pq≤p.
