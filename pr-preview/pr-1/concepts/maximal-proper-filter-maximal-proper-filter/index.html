Maximal proper filter

Source indexedLarge Sets.tex:1160

Formal statement

A proper filter F\mathcal{F}F on III is called maximal if there
is no proper filter on III that properly contains F\mathcal{F}F.

Equivalently, F\mathcal{F}F is maximal if, whenever G\mathcal{G}G is a
proper filter on III satisfying
F⊆G, \mathcal{F}\subseteq\mathcal{G}, F⊆G,
we necessarily have
F=G. \mathcal{F}=\mathcal{G}. F=G.
