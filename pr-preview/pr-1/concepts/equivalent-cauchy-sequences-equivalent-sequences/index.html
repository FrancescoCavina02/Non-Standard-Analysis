Formal statement

(Equivalent sequences). Two sequences an{a_n}an​ and bn{b_n}bn​ are equivalent iff they are eventually infinitely-close. In other words,
\begin{align*}
{a_n} \text{ and } {b_n} \text{ are equivalent } & if and only if d(a_n, b_n) = |a_n - b_n| \leq \varepsilon \cdot c = \frac{1}{\Omega} \cdot c \\
& if and only if a_n \simeq b_n
\end{align*}
