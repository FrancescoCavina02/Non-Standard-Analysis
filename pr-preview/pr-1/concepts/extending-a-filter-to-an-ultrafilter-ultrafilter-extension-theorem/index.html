Extending a filter to an ultrafilter / Theorem

Ultrafilter extension theorem

Source indexedLarge Sets.tex:1561

Formal statement

Let III be a nonempty set, and let
H⊆P(I) \mathcal{H}\subseteq\mathcal{P}(I) H⊆P(I)
have the finite intersection property. Then there exists an ultrafilter
U\mathcal{U}U on III such that
H⊆U. \mathcal{H}\subseteq\mathcal{U}. H⊆U.
In other words, every collection having the finite intersection property
can be extended to an ultrafilter.
