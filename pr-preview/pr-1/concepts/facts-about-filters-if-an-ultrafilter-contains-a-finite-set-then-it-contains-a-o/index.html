Facts About Filters / Proposition

If an ultrafilter contains a finite set, then it contains a one-element set and is principal

Source indexedLarge Sets.tex:801

Formal statement

If an ultrafilter contains a finite set, then it contains a
one-element set and is principal. Hence every nonprincipal ultrafilter
contains all cofinite sets.
